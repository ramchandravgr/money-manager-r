SMS Backup & Restore

This app does not read your message inbox. Save messages with SMS Backup & Restore, then choose that folder here.
1. Get SMS Backup & RestorePlay Store ›
Opens the SyncTech app on the Play Store. Install it, then come back here.
2. Save Messages As A File
In that app, save messages as an XML file, not a database. Pick a folder you can find again. One file name is enough.
3. Repeat That Save
An hourly schedule is enough. Let it replace the same file each time.
4. Choose That Folder Here
Go back to Transaction Scan and tap Backup Folder. Allow access to the same folder.
5. Refresh Approval Center
Open Approval Center and tap Refresh. New bank messages from that file are offered for you to accept.

Look Back sets how many months of those messages are offered. Forget Folder stops reading the folder. It does not delete the files.
