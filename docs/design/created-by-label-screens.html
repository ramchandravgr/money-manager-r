“Created by” — screens & copy

Reference for Ramchandra: every place the Android app shows the Created by {name} provenance label, mentions it in settings copy, or stores created-by data without UI yet. Generated from current Kotlin sources (2026-11-05).

Quick answer

  • Live label on a record: one screen — Transaction detail.
  • Settings copy only: Peer Device Sync footer under “Your name”.
  • Data stamped, no detail UI yet: loans, recurring, budgets, assets (see summary table).
  • Never shown: Home, lists, search, stats, approval center, Web Manage, widgets.

When the subtitle appears

  • Peer Device Sync is turned on (LanSyncIdentityStore.isLanSyncEnabled()).
  • Transaction has createdByProfileId and it is not this phone’s ownerProfileId.
  • createdByDisplayName snapshot is non-empty (sync/merge fills this).

Not shown on Home rows, search results, stats, or approval cards. MmrOwnerProfileCoordinator.resolveCreatedByLabel exists for richer rules but detail screen still uses the ViewModel helper above.
