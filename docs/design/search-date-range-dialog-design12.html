Where you will see this dialog

Only two screens host it; it is not used on Stats, Settings, or Trends.

1 — Transaction Search
  1. Home → top bar Search (magnifier).
  2. Path A: Top-right Week / Month / Year / Custom chip → choose Custom → dialog opens.
  3. Path B: Expand filters → tap Period row → dialog opens.
2 — Home Total view Excel export
  1. Home → view mode Total (ledger dropdown).
  2. Tap Export on the total accounts summary.
  3. In Money Inbox - Excel period list, choose Custom Period….
  4. Same date-range dialog; after Apply, export runs (then Share As Excel / XML if successful).

Related (not this dialog)

Stats category bulk delete uses MmrConfirmDialog (simple confirm, no dates). Calendar pickers elsewhere use DatePickerDialog (transactions, loans, manual SMS). HomeExcelExportPeriodDialog (Weekly, Last month, …) is separate; only Custom Period… opens SearchDateRangeDialog.
