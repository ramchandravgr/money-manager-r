10 alternatives per MM-overlapping component

Prefer real screen mockups? Open visual.html — miniature phones for all 100 alternatives plus a gold “shipped today” reference per section.

Money Inbox’s Home and Stats shells share patterns with classic Money Manager (Realbyte): centered month title, HomeMonthPickerDialog (Date / THIS MONTH / year chevrons / 3×4 months), Daily·Calendar·Monthly·Total tabs, Income|Expenses|Total strip, grouped ledger rows, and Stats period + Income/Expense + pie breakdown. Below: 10 distinct product directions for each overlapping surface—pick one axis at a time to avoid redesign thrash. Shipped today: see docs/home-stats-differentiation-mockups.html.

How to use this catalog

  • Pick one component where MM similarity hurts most (usually #1 Period picker + #2 Top chrome).
  • Tag “High differentiation” options change mental model; “Low effort” options preserve behavior and swap copy/chrome.
  • Compose touchpoints called out where an alternative maps to existing code (HomeMonthPickerDialog, MmrPeriodSwipeBox, MmrHeaderBar, MmrScrollableBottomBar, Stats category bridge).
  • Mixing all ten #01 variants at once will fight; pair e.g. picker #05 chips + strip #01 net hero + list #02 source threads for a coherent “Inbox-first” story.
  • Open locally: docs/design/mm-overlap-alternatives/index.html (static; no build step).
