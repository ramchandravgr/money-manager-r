Home ledger — 20 minimal ad placements

Ideas for Money Inbox Home (Daily ledger: summary strip, grouped transaction list, period chrome). Each option aims for low visual weight but enough contrast and size to count as “visible” for advertisers and users.

Product context only — not implementation. Pair with “Sponsored” labeling, frequency caps, and paid / privacy settings. Full-screen ledger mockups: home-ledger-ad-placement-fullscreens.html

03 Collapsed “tip” strip under summary (expandable)

Minimal defaultTap to expand

28dp row: “Partner offer” + chevron; expands to full mini-card once per session.

Collapsed state is minimal; expanded state satisfies visibility for fill-based ads.

Always visibleSubtle

Replace or add a narrow 4th metric slot (e.g. “Offers”) with muted styling; opens sponsored bottom sheet.

Uses existing strip real estate — high visibility without scrolling; keep distinct from financial metrics.

05 Sticky footer banner above bottom nav

Persistent50dp max

Anchor adaptive banner above the tab bar on Home only; list scrolls underneath with bottom content padding.

Classic pattern — minimal height, always visible; may compete with FAB — offset FAB upward.

06 Empty-state hero (no transactions in period)

ContextualLarge format

When ledger is empty, show one medium rectangle where the list would start — still show summary strip.

Zero clutter on busy ledgers; maximum visibility when screen has whitespace.

07 Pull-down reveal under month header

Opt-inMinimal

Small affordance on month row: “pull for offers”; rubber-band reveals 80dp ad panel (once per day).

Power users skip it; engaged users see a clear, full-width unit.

08 Inline after carry-over row

Finance-adjacentOne slot

When carry-over appears on first day of period, place a single native ad directly below that read-only row.

Natural pause in scanning; message can be savings / credit themed without mimicking a transaction.

09 Medium rectangle at list midpoint

ScrollMREC 300×250

At ~50% of scroll height (or after 15 txn rows), insert centered MREC with 12dp vertical margin.

Visible during normal browsing of a full month; not shown on very short lists (<8 rows).

10 “Sponsored insight” text line

Ultra-minimalText + link

Single line under summary: muted “Sponsored: Compare FD rates →” — no image; tap opens landing.

Lowest visual weight; visibility comes from placement + periodic rotation of copy.

11 Floating companion chip (FAB-adjacent)

VisibleNon-blocking

Small pill stacked 8dp above FAB: brand logo only; dismiss × persists 7 days.

Always on screen in Daily view; keep ≤40dp height so FAB remains primary action.

12 End-of-scroll footer card

Non-intrusiveFull width

Last item in LazyColumn: card “You’ve reached the end” + sponsored unit (not mistaken for txn).

Minimal for users who don’t scroll far; visible for thorough reviewers.

13 View-mode dropdown sponsor line

Rare exposureMicro

When opening Daily | Weekly | Monthly selector, show one text ad in sheet footer (finance category only).

Minimal on main ledger; visible in intentional navigation moment.

14 Time-of-day slot (morning / evening)

ScheduledOne banner

Show top banner only 7–10am or 6–9pm — commute windows; hide midday for cleaner ledger.

Balances minimal daily feel with predictable high-visibility windows.

15 Category-themed native (from spend signals)

RelevantOn-device

If week’s top category is Food, show one native ad in ledger styled like a “deal” row — no PII off device.

Higher CTR with same footprint as idea #2.

16 Swipe-period interstitial (light)

IntermittentFull screen

Every 5th month swipe (not every swipe): 3s skippable interstitial before new period loads.

Not minimal in moment, but keeps main ledger clean — use sparingly.

17 Divider + label between weeks (Weekly view)

Weekly modeBanner

In Weekly home mode only, thin banner between week sections — hidden in Daily to reduce noise.

Targets users already thinking in week boundaries.

18 Outstream video thumbnail row

Thumb + playMuted autoplay off

One 16:9 thumbnail row between groups; plays only on tap (compliance-friendly).

More visible than static banner; keep height capped (~120dp).

19 House promo for premium (ad replacement)

MinimalUpsell

Same slot as #1 but copy: “Remove ads — Upgrade” with soft coral accent; rotates with third-party fill.

Single slot stays visible; improves monetization mix without new UI.

20 Hybrid: one global slot + rules engine

Recommended patternPolicy

Implement one physical placement (e.g. #1 or #2) and rotate formats by rules: empty list → MREC; >20 txns → native; paid user → off.

MinimalOnly one ad container in layout; no stacking.
VisibleFormat escalates when scroll depth or session count increases.

Avoid combining #5 + #1 + #2 on the same screen — pick a primary + optional empty-state boost (#6).
