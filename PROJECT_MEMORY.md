# Money Inbox (MMR) — Project Memory & Architecture Tracker

## 1. Project Overview & Vision

**Money Inbox** (repo codename **MMR**, package `com.rrparallelstudio.miapp`) is an **offline-first, privacy-centric personal finance tracking Android application** built entirely with modern Android technologies (Kotlin, Jetpack Compose, Hilt, Room, and Navigation). Store-facing tagline: *Paste bank SMS. Approve before recording.*

### Core Principles
- **100% Offline & Local**: No external backend servers or third-party cloud finance APIs. All user financial data is kept securely on-device.
- **Rule-Based SMS Parser with Explicit Approval**: User-provided bank SMS text (paste; planned XML import) is parsed **locally**, normalized, deduplicated with cryptographic hashing, and routed to a **Transaction Approval Center** for review, edit, approve, or reject before saving.
- **Robust Financial Ledger**: Supports standard expenses, income, inter-account transfers (from account → account or loan), and loan payment linkages.
- **Rich Analytics & Loan Tracking**: Local aggregation for category-wise breakdowns, spending trends, loan repayment schedules, and outstanding balances.

## 4. Architecture & Package Structure

**Package rename (2026-11-06):** Android `applicationId` / `namespace` are **`com.rrparallelstudio.miapp`**. Kotlin sources live under **`com.rrparallelstudio.miapp.*`** (was `com.mmr.*`). **Breaking:** backups with `appId` `com.mmr.app` are rejected. **Migrating an old signed archive:** do not hand-edit the zip — changing `backup.json` invalidates `payloadSha256` / HMAC `signature` in `manifest.json`. Use **`scripts/migrate_backup_app_id.py`** (rewrites `appId`, recomputes SHA-256 + **`BackupIntegrity`** signature), then `adb push` the new `.mibxbac` for import. `BackupIntegrity` HMAC key string was updated with the new package so casual edits of old exports fail as intended.
