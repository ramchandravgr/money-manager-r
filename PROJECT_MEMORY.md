# Money Inbox (MMR) — Project Memory & Architecture Tracker

## 1. Project Overview & Vision

**Money Inbox** (repo codename **MMR**, package `com.mmr.app`) is an **offline-first, privacy-centric personal finance tracking Android application** built entirely with modern Android technologies (Kotlin, Jetpack Compose, Hilt, Room, and Navigation). Store-facing tagline: *Scan bank SMS. Approve before recording.*

### Core Principles
- **100% Offline & Local**: No external backend servers or third-party cloud finance APIs. All user financial data is kept securely on-device.
- **Rule-Based SMS Parser with Explicit Approval**: Scans bank and merchant transaction SMS messages locally, normalizes them, detects duplicates via cryptographic hashing, and routes them to a **Transaction Approval Center** where users can review, edit, approve, or reject entries before saving.
- **Robust Financial Ledger**: Supports standard expenses, income, inter-account transfers (from account → account or loan), and loan payment linkages.
- **Rich Analytics & Loan Tracking**: Local aggregation for category-wise breakdowns, spending trends, loan repayment schedules, and outstanding balances.

### Loans (`core/loan/`, `feature/loan/`)

- **Disbursal**: Stored as `LoanEntity.openingDate`; interest accrual and schedule anchors use `disbursalDateMillis()` extension. **Principal** on the linked **LOAN** account **opening balance** (`LoanRepositoryImpl.createLoan`) remains the liability source of truth. **Also** posts an informational `TRANSFER` on the **disbursal calendar day** (`LoanLedgerCoordinator.createInitialDisbursalTransaction`, `sourceReferenceId` `loan_disbursal:{loanId}:{millis}`) when a primary account exists — visible in Home/Web transaction lists, **excluded** from income/expense (`TransactionCashFlow.isLoanPrincipalMovement`) and from account balance recompute (`skipsAccountBalanceRecompute`). **Top-ups** use `loan_topup:…` with the **top-up date** (`LoanDateUtils.normalizeLoanCalendarDay`); same exclusions. **Repayments** still count as expense (borrowed) / income (lent) via `TransactionCashFlow`.

- **Flexible repayment**: No planned EMI schedule required.
